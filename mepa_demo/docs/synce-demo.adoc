= SyncE Demo Application

== Overview

Synchronous Ethernet (SyncE) is an ITU-T standardized clock distribution technology that enables
the transmission of frequency synchronization over Ethernet physical links. Unlike ordinary Ethernet,
SyncE ensures that all network elements (NEs) participating in the network operate using a common frequency,
significantly enhancing stability and timing accuracy.

The SyncE Demo Configuration Application provides a command-line interface (CLI) that allows users to configure, enable, disable,
and monitor SyncE clock settings on supported PHY devices. This demo illustrates how to select recovered clock sources, output destinations,
frequencies, and squelch controls based on the PHY family.

The SyncE Demo Application is designed to:

* Demonstrate how SyncE configuration is applied on various PHY families
* Only valid options for the detected PHY and port mode are presented in the CLI
* Allow users to interactively choose:
** Clock source (e.g., recovered line/host clocks, copper/serdes, srefclk)
** Clock destination (SCKOUT, CKOUTx, RCVRCLKx)
** Output frequency (based on destination and hardware restrictions)
** Squelch configuration (if supported)

== CLI Command and Usage

----
mepa-cmd phy synce_conf <port_no> <enable|disable>
----

[cols="1,3",options="header"]
|===
| Argument   | Description
| <port_no>  | PHY port index (0-based)
| enable     | Enables SyncE output configuration
| disable    | Disables the selected SyncE destination
|===

== Supported PHY Families and Their Options

=== VSC8258

*Sources*: `line0`, `line1`, `line2`, `line3`, `host0`, `host1`, `host2`, `host3`, `srefclk` +
*Destinations*: `sckout`, `ckout0`, `ckout1`, `ckout2`, `ckout3` +

*Frequency based on operating mode*: +
* SCKOUT: 125, 156.25 MHz +
* CKOUT (1G): 125, 62.5 MHz +
* CKOUT (10G LAN): 322.27, 161.13 MHz +
* CKOUT (10G WAN): 311.04, 155.52 MHz +

*Squelch options*: `none`, `link_line0`, `link_line1`, `link_line2`, `link_line3`

=== VSC8584

*Sources*: `copper`, `serdes` +
*Destinations*: `rcvrclk1`, `rcvrclk2` +
*Frequencies*: 25, 31.25, 125 (MHz) +

=== LAN8814

*Sources*: `copper`, `serdes`, `clock_in_1`, `clock_in_2` +
*Destinations*: `rcvrclk1`, `rcvrclk2` +
*Frequencies*: 25, 31.25, 125 (MHz) +

=== LAN80XX

*Sources*: `srefclk`, `ptp_ltc`, `line0`, `line1`, `line2`, `line3`, `host0`, `host1`, `host2`, `host3`, `disabled` +
*Destinations*: `rckoutA`, `rckoutB` +

*Frequency based on source and port speed*: +
* SREFCLK: 75, 37.5 MHz +
* PTP_LTC: 79.58, 39.79 MHz +
* LINE0-3 / HOST0-3: +
  - 1G: 125, 62.5, 31.25, 15.625 MHz +
  - 10G: 128.90625, 64.453125, 32.2265625 MHz +
  - 25G: 80.56640625 MHz +
* DISABLED: clock output off

NOTE: For LAN80XX, the **clock source and squelch source must be the same**. Selecting a mismatched squelch source will result in an error.
